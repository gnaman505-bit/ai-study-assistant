# AI Study Assistant (StudyAI)

A full-stack web application designed to help students process lecture notes, chat with an AI tutor, and generate study flashcards.

## Features
- **Notes & Processing:** Summarize and extract key concepts from study notes.
- **AI Tutor Chat:** Interactive chat interface for asking questions, getting concept explanations, and brainstorming.
- **Flashcards:** Automatically generate and review study flashcards.
- **Cloud Persistence:** Saves chat history and study materials using Firebase.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide React
- **Backend & Database:** Firebase (Firestore & Authentication)
- **AI Engine:** Google Gemini API
